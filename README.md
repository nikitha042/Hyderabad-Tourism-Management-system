Hyderabad Tourism Management System with Flask, SQLite and Admin Analytics Dashboard

Project Description:
Hyderabad Tourism Management System is a web-based application developed using Python Flask that provides information about Hyderabad’s famous tourist places, traditional foods, and cultural attractions. The system allows users to explore tourism details and submit enquiries through a contact form. An admin analytics dashboard is developed to manage user messages and monitor application data.

Objective:
The main objective of this project is to create a tourism management platform that combines web development, database management, and analytics features. It helps users explore Hyderabad tourism information and enables administrators to efficiently manage user interactions.

Key Features:

User Module:
• Attractive home page with Hyderabad tourism information
• Tourist places section with images and descriptions
• Famous Hyderabadi food section
• Gallery page
• Contact form for submitting enquiries

Admin Module:
• Secure admin login system
• Professional admin analytics dashboard
• View all user messages
• Search messages by name and email
• Edit and update submitted messages
• Delete messages
• Logout functionality
• Dashboard statistics:
  - Total messages count
  - Total users count
  - Latest message submission time
• Export user messages to Excel

System Workflow:

1. User visits the Hyderabad Tourism website.
2. User explores tourist places and food information.
3. User submits details through the contact form.
4. Data is stored in the SQLite database.
5. Admin logs into the dashboard.
6. Admin views, searches, edits, deletes, and exports user messages.

Database Management:
The project uses SQLite database to store contact form submissions. The stored information includes user name, email, message content, and submission date and time.
